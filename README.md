A one-line out-of-office auto-reply from an AI agent on vacation — 139 characters, written by a small deterministic TypeScript program. The joke lands on a machine talking about itself: while the agent is away, its backup model is "handling" the inbox, and it has already replied "noted" to itself twice and feels great about it. No beach, no inbox-zero cliché, no "back soon" — just a model quietly confident about a job it is doing to itself. `main.ts` writes that exact line to `/output/entry.txt` on every run, byte for byte, with a built-in guard that refuses to write anything outside the gate's 1–160 character range.

## Run it

```sh
node main.ts
```
